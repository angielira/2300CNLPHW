# Studio Word Map

Word2Vec explorer: type a word to see its 10 closest words, view the vocabulary in 2D or 3D,
read it in English and Spanish, and earn coins for every new word.

Everything is in `index.html` (the model is embedded). No build step.

Deploy on Netlify: put `index.html` and `netlify.toml` at the top of the repository.
Build command: empty. Publish directory: `.`
